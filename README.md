# 🔐 Random Password Generator

A modern and beginner-friendly Password Generator built using HTML, CSS, and JavaScript.

## ✨ Features

* Generate random passwords instantly
* Three password strength levels:

  * 🟢 Easy
  * 🟡 Medium
  * 🔴 Hard
* Clean and animated user interface
* Beginner-friendly code structure
* Fast and lightweight

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📸 Preview

Select a password strength level and click the **Generate** button to receive a random password instantly.

## 📂 Project Structure

```text
├── index.html

├── script.js

```

## 🛠️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/random-password-generator.git
```

2. Open the project folder

```bash
cd random-password-generator
```

3. Open `index.html` in your browser
